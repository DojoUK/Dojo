# QA & Testing Strategy

The QA and testing strategy for Dojo lives in this repo under
[`docs/qa-strategy/`](docs/qa-strategy/README.md). Start with the landing page there: it
names what the tests protect, the hard rules every change is held to, and the five-phase
rollout.

The tracked work is GitHub issues labelled
[`qa-strategy`](https://github.com/DojoUK/Dojo/issues?q=is%3Aissue+label%3Aqa-strategy),
organised as one milestone per phase (QA Phase 0 to 4). Decisions still open are issues
titled `[Decision] ...`.

Please do not restate the strategy elsewhere; change it there so it lives in exactly one
place. The pull request template's checklist is the strategy's hard rules in the same words.
